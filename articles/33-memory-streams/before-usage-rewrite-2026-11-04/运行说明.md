# 运行说明

本目录代码依赖 POSIX.1-2008 内存流接口，头文件前定义 _POSIX_C_SOURCE 200809L。
无文件系统数据写入。

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow report.c memory_probe.c -o /tmp/memory-probe
/tmp/memory-probe
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow report.c memory_test.c -o /tmp/memory-test
/tmp/memory-test
```

verify.py 自动编译运行并记录实际输出、环境和退出码，同时核对正文代码片段和 HTML。
需要已有 wechat.html，并安装 bs4 与 Pillow。
