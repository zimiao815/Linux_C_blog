# 标准 I/O 库第 19 期：内存流

核心问题：如何让接受 FILE * 的代码直接输出到内存？
主线：保留原输出函数，通过两种内存流改变输出目标。
范围：fmemopen 的调用者固定数组、open_memstream 的动态缓冲、
刷新后获取结果、继续写入后的指针有效期、关闭和释放。
实验：固定文本 count=3；动态 hello 刷新后 len=5，追加 ", C" 关闭后 len=8。
工程函数：report_to_memory 接收现成数组，复用 render_report，
检查输出长度、终止符空间以及 fclose 失败。
不展开随机定位、宽字符流和内部实现源码。本期本地交付，不自动上传。
