# 运行说明

正文两组代码分别属于 fixed_example.c 和 dynamic_example.c 的 main 函数。
在各自源文件开头保留 _POSIX_C_SOURCE 与头文件。

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g fixed_example.c -o /tmp/memory-fixed
/tmp/memory-fixed
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g dynamic_example.c -o /tmp/memory-dynamic
/tmp/memory-dynamic
```

预期分别输出 hello 和 text=hello, len=5。
verify.py 编译运行两个正文示例，并运行已有刷新与容量边界测试。
依赖 bs4、Pillow 及已有的 wechat.html；结果写入 verification.json、actual-output.txt 和 article-verification.json。
示例仅在记录中的 macOS 平台实测，没有声称 Linux 实测。
