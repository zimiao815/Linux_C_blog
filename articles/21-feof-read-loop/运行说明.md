# 第 7 期配套运行说明

命令在本目录执行。正文第一章使用 `feof_short.c`；工程章的两个文件 `copy_stream.c` 和 `copy_main.c` 必须一同编译。

## 工程示例

```sh
cc -std=c17 -Wall -Wextra -Wpedantic \
  -Wconversion -Wshadow -O0 -g copy_stream.c copy_main.c -o copy_stream
printf A | ./copy_stream
```

预期输出一个 A，无换行，退出为 0。复制函数已刷新标准输出；输入、输出错误均返回 -1，调用入口立即用 perror 报告原因并返回 1。

复制函数借用流。其他调用者如果自行打开了文件，需按资源归属关闭，并检查关闭结果；复制失败不能被关闭成功覆盖。

## 完整验证

```sh
python3 verify_short.py
```

验证器在临时目录严格编译完整程序，检查四种探针输入、两种复制输入和四条失败路径。记录见 short-verification.json。目录读取失败及文件大小限制均仅作为本机已实测的故障输入；未在 Linux 主机运行。
