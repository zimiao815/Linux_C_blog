NAME
feof — test end-of-file indicator on a stream
SYNOPSIS
#include <
stdio.h
>
int feof(FILE *
stream
);
DESCRIPTION
[
CX
]
The functionality described on this reference page is aligned with the ISO C standard. Any conflict between the
requirements described here and the ISO C standard is unintentional. This volume of POSIX.1-2024 defers to the ISO C
standard.
The
feof
() function shall test the end-of-file indicator for the stream pointed to by
stream
.
[
CX
]
The
feof
() function shall not change the setting of
errno
if
stream
is valid.
RETURN VALUE
The
feof
() function shall return non-zero if and only if the end-of-file indicator is set for
stream
.
ERRORS
No errors are defined.
