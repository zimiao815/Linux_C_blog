# 研究记录

## 接口事实

C17 `fscanf` 声明为 `int fscanf(FILE * restrict stream, const char * restrict format, ...)`。返回成功匹配并赋值的输入项目数，可以为 0；如果第一次转换前遇到输入结束且没有匹配失败，返回 `EOF`。

转换失败分为输入失败和匹配失败。输入项不符合转换格式时是匹配失败，冲突字符及其后续输入保持未读。POSIX 明确说明，转换在冲突输入上终止时，冲突字符留在输入流中。

## 实验环境

- macOS 14.8.8 x86_64
- Apple clang 16.0.0（clang-1600.0.26.6）
- 编译：`cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g`
- 未在 Linux 主机实测

## 实验结果

临时流输入 `42x\n7\n`，连续执行两次 `%d`，消费 `x` 后再次执行：

```text
first=1 value=42
second=0 value=42
blocked=x
recovered=1 value=7
```

第二次转换返回 0，`value` 保持 42，`x` 由后续 `fgetc` 消费，第三次转换成功读取 7。
