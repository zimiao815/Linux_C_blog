# 研究记录

环境：macOS 14.8.8、Apple clang 16.0.0。

编译：

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g atomic_io_demo.c -o atomic_io_demo
```

运行：`./atomic_io_demo`

实验目标：两个子进程分别用 `O_APPEND` 写记录，验证每次写入都从当前文件尾开始；用 `pwrite` 在明确偏移写入，验证它不依赖共享 `f_pos`；用临时文件同步后 `rename`，验证读者只看到旧文件或完整新文件。

资料：[Linux `open(2)`](https://man7.org/linux/man-pages/man2/open.2.html)、[Linux `pwrite(2)`](https://man7.org/linux/man-pages/man2/pwrite.2.html)、[Linux `rename(2)`](https://man7.org/linux/man-pages/man2/rename.2.html)、[POSIX `rename`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/rename.html)。
