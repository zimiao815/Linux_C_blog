# 文件 I/O 的原子操作

- 核心问题：多进程写同一文件为什么互相覆盖，怎样选择能保持边界的写入方式？
- 一句话结论：需要追加时用 `O_APPEND`，需要固定位置写入时用 `pwrite`，需要整体替换文件时用“临时文件写完并同步后 `rename`”；不要把共享的 `lseek` + `write` 当作原子操作。
- 适用范围：POSIX/Linux 文件描述符语义；实验在 macOS 14.8.8、Apple clang 16 上验证，Linux 的具体文件系统还应按部署环境复测。
- 不处理：数据库事务、分布式文件系统一致性、文件锁的完整设计、`O_DIRECT` 和存储设备断电保护。
