# 文件与目录·第 3 篇：opendir / readdir

- 核心问题：如何正确遍历一个目录，并区分遍历结束和读取错误？
- 直接结论：每次 readdir 前将 errno 清零；返回 NULL 时立即读取 errno，0 表示结束，非零表示错误；所有已打开目录流统一由 closedir 收尾。
- 范围：POSIX.1-2024 目录流接口；glibc 2.40 和 Linux 6.6 的批量读取机制。实验在 macOS 上运行，Linux 机制通过固定版本源码核对。

- 学习者：区分 DIR *、fd、struct file、目录 inode、struct dirent 及缓冲位置。
- 编程者：掌握借用记录、复制名字、关闭资源和处理部分结果的边界。
