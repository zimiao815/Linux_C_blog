# `lseek` 与文件定位

- 核心问题：文件偏移量是什么，`lseek` 到文件末尾之外再写会发生什么？
- 一句话结论：普通文件有一个与打开文件描述共享的当前偏移量，`lseek` 只改变这个偏移量；偏移移到 EOF 之外再写会留下空洞，形成稀疏文件；`O_APPEND` 文件每次写入前都会把偏移移到当时的 EOF，不能靠 `lseek` 改变追加位置。
- 适用范围：POSIX `lseek`/`open` 语义，实验在 macOS/Linux 类 Unix 上验证；稀疏文件的实际磁盘占用取决于文件系统。
- 不处理：`pread`/`pwrite` 的并发设计、文件锁、`fsync` 落盘和跨进程原子写入细节。
