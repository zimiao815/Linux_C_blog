# 研究记录

环境：macOS 14.8.8，Apple clang 16.0.0。

编译：`cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g lseek_demo.c -o lseek_demo`

运行：`./lseek_demo`

实际输出：

```text
after writing 3 bytes, offset = 3
seek to offset 5, lseek returned = 5
after writing one byte, offset = 6
file size = 6 bytes
append fd seek to 0, offset = 0
after O_APPEND write, offset = 7
file size = 7 bytes
```

资料：[POSIX lseek](https://pubs.opengroup.org/onlinepubs/9699919799/functions/lseek.html)、[POSIX open](https://pubs.opengroup.org/onlinepubs/9699919799/functions/open.html)、[Linux lseek(2)](https://man7.org/linux/man-pages/man2/lseek.2.html)、[Linux open(2)](https://man7.org/linux/man-pages/man2/open.2.html)。
