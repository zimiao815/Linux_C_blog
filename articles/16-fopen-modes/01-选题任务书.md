# 标准 I/O 库第 2 篇：fopen 的打开模式

- 核心问题：怎样选择不会误清空文件的打开模式？
- 直接结论：r/w/a 决定保留、截断、创建和追加策略，+ 只增加读写能力。已有普通文件成功以 w 或 w+ 打开时被截断到零；r+ 保留但要求已存在；a/a+ 写入追加到末尾。
- 适用条件：普通文件、有效路径、权限允许；公开语义按 POSIX.1-2024，glibc 2.40、Linux v6.6 源码说明机制。
- 实测平台：macOS 14.8.8 x86_64，Apple clang 16.0.0。没有 Linux 运行环境，不混写两者。
- 不展开：缓冲策略、落盘、完整更新流切换规则、fdopen、文件定位教程、网络文件系统或多进程日志协议。
- 补充边界：b 在 POSIX 下不改变打开语义；wx 拒绝覆盖已有文件；不把先检查后打开当成防覆盖方案。
- 搜索者：拿到六种模式对照表和可复现实验。
- 学习者：理解 mode 到 open 标志、再到截断文件长度的路径。
- 编程者：分清不截断、原地覆盖、追加、重新生成和只许新建。
- 求职者：能回答 w+ 与 r+、b 与 +、更新流切换边界。
