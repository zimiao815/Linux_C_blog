# 运行说明

在本目录编译运行，示例仅创建 mkstemp 临时文件，测试结束后清理。

```sh
cc -std=c17 -Wall -Wextra -Wpedantic fdopen_probe.c -o /tmp/fdopen-probe
/tmp/fdopen-probe
cc -std=c17 -Wall -Wextra -Wpedantic save_fd.c save_fd_test.c -o /tmp/save-fd-test
/tmp/save-fd-test
```

完整自动验证包含额外的转换警告、ENOMEM 注入测试和管道写出错误测试：

```sh
/Users/zhaodan/.workbuddy/binaries/python/envs/default/bin/python verify.py
```

实际输出保存在 actual-output.txt；verification.json 保存环境、编译选项和退出码。
注入测试只在测试构建中用 -Dfdopen=fail_fdopen 替换接口，生产函数源代码不变。
