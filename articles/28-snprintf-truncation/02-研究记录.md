# 研究记录

## 接口事实

C17 `snprintf` 声明为 `int snprintf(char * restrict s, size_t n, const char * restrict format, ...)`。当 `n` 非零时，最多写入 `n-1` 个字符，并写入终止空字符。返回值是容量足够时本应写入的字符数，不包含终止空字符；编码错误时返回负值。

当 `n` 为 0 时，不写入字符，`s` 可以是空指针，仍返回完整结果所需的字符数。输出完整写入的条件是返回值非负且小于 `n`。

## 实验环境

- macOS 14.8.8 x86_64
- Apple clang 16.0.0（clang-1600.0.26.6）
- 编译：`cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g`
- 未在 Linux 主机实测

## 实验结果

```text
small ret=11 text=value=1 truncated=1
exact ret=7 text=1234567 truncated=0
probe ret=11
```

容量为 8 时，长结果保留 7 个字符并补 `\0`；返回值 11 用于判断截断。`n=0` 查询返回完整结果长度 11。
