# 标准 I/O 库第 14 篇：snprintf 与截断判断

- 核心问题：如何判断 `snprintf` 的输出是否被截断？
- 标题：`snprintf` 返回 11，为什么只剩 7 个字符？
- 结论：返回值是空间足够时本应写入的字符数，不包含 `\0`；当返回值非负且大于等于容量时发生截断。
- 范围：返回值、容量、终止符、`n=0` 查询所需空间和负值错误返回。
- 依赖：无前置篇目，作为标准 I/O 格式化输出的独立主题。
- 实验：容量为 8 的缓冲区测试长结果、刚好容纳结果和 `snprintf(NULL, 0, ...)`。
- 语言要求：短段落，类比明确说明对应关系和边界；工程代码使用真实 C，不用伪代码或 shell 代替。
