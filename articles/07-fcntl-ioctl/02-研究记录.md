# 研究记录

环境：macOS 14.8.8、Apple clang 16.0.0。

编译：

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g fcntl_ioctl_demo.c -o fcntl_ioctl_demo
```

实验：对普通文件使用 `fcntl` 读取并修改 `O_APPEND`，用 `F_DUPFD_CLOEXEC` 复制描述符；向管道写入 3 个字节，再用 `ioctl(FIONREAD)` 查询读端当前可读字节数。

资料：[Linux `fcntl(2)`](https://man7.org/linux/man-pages/man2/fcntl.2.html)、[Linux `ioctl(2)`](https://man7.org/linux/man-pages/man2/ioctl.2.html)、[POSIX `fcntl`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/fcntl.html)。
