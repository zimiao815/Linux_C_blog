# 研究记录

环境：macOS 14.8.8、Apple clang 16.0.0。

编译：

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g fcntl_demo.c -o fcntl_demo
```

实验：对普通文件用 `F_GETFL` / `F_SETFL` 读取并修改 `O_APPEND`，用 `F_DUPFD_CLOEXEC` 复制描述符；再用两个进程竞争同一文件的建议性记录锁，观察第二个进程得到 `EACCES` 或 `EAGAIN`。

实际输出：

```text
F_GETFL/F_SETFL: before=normal after=append
F_DUPFD_CLOEXEC: original=3 copy=4
F_SETLK in child: blocked (Resource temporarily unavailable)
```

资料：[Linux `fcntl(2)`](https://man7.org/linux/man-pages/man2/fcntl.2.html)、[POSIX `fcntl`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/fcntl.html)。
