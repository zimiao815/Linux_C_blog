# 标准 I/O 库第 11 篇：fread 与读取计数

- 核心问题：`fread` 返回的数量究竟代表什么？
- 标题：`fread` 返回 2，到底读了几个字节？
- 结论：`fread` 返回成功读取的元素数，不是字节数；`size=1` 时元素数才等于字节数。返回值小于 `nmemb` 后，要检查 `ferror` 和 `feof`。
- 范围：元素数与字节数、短读、末尾不足一个元素、`size` 或 `nmemb` 为 0 的边界。
- 依赖：标准 I/O 库第 7 期的 EOF 与错误状态，第 9 期的输入边界。
- 实验：10 个字节分别按 4 字节元素和 1 字节元素读取，对比返回值、文件位置和 EOF 状态。
- 语言要求：短段落，使用现实类比时说明对应关系和边界；工程代码使用真实 C，不用伪代码或 shell 代替。
