# 研究记录

## 接口事实

C17 `fread` 声明为 `size_t fread(void * restrict ptr, size_t size, size_t nmemb, FILE * restrict stream)`。函数读取最多 `nmemb` 个元素，每个元素 `size` 字节，返回成功读取的元素数，而不是字节数。

如果 `size` 或 `nmemb` 为 0，返回 0，数组内容和流状态不变。返回值小于 `nmemb` 时，原因是遇到 EOF 或发生错误。POSIX 说明文件位置按成功读取的字节推进；如果读取了不完整元素，该元素的值未指定。

## 实验环境

- macOS 14.8.8 x86_64
- Apple clang 16.0.0（clang-1600.0.26.6）
- 编译：`cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g`
- 未在 Linux 主机实测

## 实验结果

程序向临时文件写入 10 个字节，然后从头读取：

```text
size=4 nmemb=3 returned=2 complete_bytes=8 pos=10 eof=1
size=1 nmemb=10 returned=10 complete_bytes=10 pos=10 eof=0
```

第一轮返回 2 个完整元素，文件位置推进到 10，并设置 EOF。第二轮以 1 字节为元素，返回值为 10；本次请求完整满足，EOF 尚未设置。
