# 运行说明

在本目录编译：

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g \
  getline_probe.c -o getline_probe
printf 'short\nthis-is-a-long-line-without-a-fixed-limit\nlast' | ./getline_probe
```

输出：

```text
line=1 len=6 cap=8 newline=1
line=2 len=42 cap=64 newline=1
line=3 len=4 cap=64 newline=0
done lines=3 eof=1
```

空输入应输出：

```text
done lines=0 eof=1
```
