# 标准 I/O 库第 15 篇：ftell 与流的位置

- 核心问题：为什么 `ftell` 和底层 fd 的偏移量可能不同？
- 标题：`ftell` 返回 1，底层 fd 为什么已经到 26？
- 结论：`ftell` 返回流的位置指示器；标准 I/O 预读可能让底层 fd 偏移领先。普通流定位使用 `ftell`、`fseek`，混用 fd 时必须遵守 POSIX 活动句柄规则。
- 范围：预读缓冲、逻辑位置、`fseek`、`fileno`、`lseek`，限定普通可定位文件。
- 依赖：标准 I/O 库第 3 期文件描述符，第 11 期读取缓冲相关概念。
- 实验：26 字节临时文件只读一个字符，对比 `ftell` 和 `lseek` 观察到的位置；再用 `fseek` 定位到 10。
- 语言要求：短段落，类比明确说明对应关系和边界；工程代码使用真实 C，不用伪代码或 shell 代替。
