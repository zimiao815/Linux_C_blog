# 运行说明

在本目录编译并运行：

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g \
  fwrite_probe.c -o fwrite_probe
./fwrite_probe
```

输出应为：

```text
normal returned=3 requested=3 bytes=12 flush=0 pos=12 error=0
readonly returned=0 requested=3 error=1
```

示例使用 `/dev/null` 的只读模式制造写错误，适用于 macOS 和常见 Linux 环境。
