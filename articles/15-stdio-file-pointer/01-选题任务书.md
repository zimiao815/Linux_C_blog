# 标准 I/O 库第 1 篇：FILE * 与文件描述符

- 核心问题：`fopen` 返回的 `FILE *` 究竟指向什么，与 fd 有什么关系？
- 直接结论：`FILE *` 指向用户态流对象，库用它管理缓冲和状态；POSIX 普通文件流关联底层 fd，`fileno` 返回已有描述符。
- 适用范围：普通文件流的公开接口以 POSIX.1-2024 为依据；内部对象用 glibc 2.40 和 Linux v6.6 源码说明。
- 相邻选题边界：不展开打开模式、缓冲策略、刷新持久化、EOF 循环、定位、`fdopen` 所有权转移和活动句柄规则。EOF 只作为流保存状态的可观察证据；资源归属仅说明 `fileno` 不复制 fd。
- 搜索者：看到正确取 fd 和查询状态的方法。
- 学习者：区分 `FILE`、整数 fd、`struct file`、inode。
- 编程者：选择接口，并用单一清理出口关闭流。
- 求职者：能给出对象关系和内存流例外。
