# 研究记录：`mkdir` 与多级目录

## 核心事实与依据

| 技术判断 | 直接资料 | 核验结果 |
| --- | --- | --- |
| `mkdir` 只创建路径最后一个目录，父目录必须已存在 | POSIX mkdir；Linux mkdir(2) | 单级程序对 `one/two` 返回 ENOENT |
| `EEXIST` 表示目标名字已存在，不能直接等同于目录可用 | POSIX mkdir；Linux mkdir(2) | 递归函数收到 EEXIST 后用 stat 确认类型 |
| 路径前缀普通文件会产生 ENOTDIR | POSIX mkdir；Linux mkdir(2) | one/file/child 受控实验返回 ENOTDIR |
| 新目录模式受进程 umask 影响 | POSIX mkdir；Linux mkdir(2)、umask(2) | 正文不把 0777 写成最终权限保证 |
| 创建需要父目录写权限和路径搜索权限 | POSIX mkdir；path_resolution(7) | 工程章节按目录权限拆开说明 |
| `mkdirat` 可把相对路径起点绑定到目录 fd，降低路径变化暴露 | POSIX mkdirat | 正文明确其不自动递归，完整方案留后文 |
| 目录项与 inode 的创建由文件系统完成，内部布局不属于应用 API | POSIX mkdir；Linux VFS 文档语义 | 机制图只表达接口可观察关系 |
| 路径循环仍有替换窗口 | POSIX mkdir 对 mkdirat 目的的说明 | 不把 stat 确认写成消除 TOCTOU |

## 实验记录

2026-10-04 在 macOS 14.8.8 / Darwin 23.6.0 x86_64 上，用 Apple clang 16.0.0 执行 `python3 verify.py`。两个程序都用 `-std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g` 编译，无警告。

- `mkdir_once one/two`：退出 1，stderr 为 `mkdir one/two: No such file or directory`。
- `mkdir_p one/two/three`：退出 0，输出 `ok: one/two/three`。
- 重复执行同一命令：退出 0，说明 EEXIST 后目录确认分支成功。
- `one/file` 是普通文件时创建 `one/file/child`：退出 1，输出 `Not a directory`。
- 空路径和缺少参数：退出 1；绝对路径、末尾斜杠：成功。

完整 stdout、stderr、退出码和编译器版本写入 verification.json。Linux 没有可用运行环境，因此 Linux 部分只引用固定规范和手册，不伪造 Linux 实测输出。

## 实现边界

`mkdir_p.c` 使用 `strdup` 复制路径，逐个临时截断前缀，不写死 PATH_MAX。`stat` 默认跟随末尾符号链接，因此指向目录的已有链接会被接受；这适合普通工具，不适合把目录树当安全边界的场景。代码处理 EINTR 不是必需的，因为示例使用的 mkdir/stat 调用在本实现里直接按返回值处理；若上层要重试，应按接口和场景定义策略。

没有测试真实权限拒绝、只读文件系统、网络文件系统和恶意并发替换，也没有声称 `mkdir_p` 具备安全递归创建能力。`mkdirat` 和目录 fd 方案在后续相对路径与 TOCTOU 选题中展开。
