# 研究记录

## 接口事实

POSIX.1-2024 的 `fgets` 声明为 `char *fgets(char *restrict s, int n, FILE *restrict stream)`。函数读取最多 `n-1` 个字节，遇到换行时把换行一并写入数组；数组末尾追加空字符。若在读取任何字节前遇到 EOF，返回空指针；发生错误时设置错误指示器并返回空指针。

## 实验环境

- macOS 14.8.8 x86_64
- Apple clang 16.0.0
- 编译：`cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g`
- 未在 Linux 主机实测

## 实验结果

`fgets_probe.c` 使用 `char buf[8]`，对以下输入执行读取：

```text
abcdefghi\nlast
```

实际输出：

```text
part=1 len=7 newline=0
part=2 len=3 newline=1
part=3 len=4 newline=0
done parts=3 eof=1
```

附加验证：短行带换行、空输入、最后一行无换行、目录作为标准输入时的读取错误。结果保存于 `verification.json`。
