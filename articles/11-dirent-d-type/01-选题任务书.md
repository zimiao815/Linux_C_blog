# 文件与目录第 4 篇：d_type 与可靠类型判断

- 核心问题：为什么不能假定每条目录记录都有确定的 d_type，遇到未知值如何分类？
- 核心结论：已识别的类型用于列表分类；未知值或未处理值用 fstatat 补查，保持不跟随最终符号链接的语义，失败报告而不猜测。
- 范围：单层目录遍历与对象自身的类型；区分分类完整性、可移植性和后续操作竞态。
- 前置知识：stat / lstat 的对象选择，opendir / readdir 的循环和资源管理。
- 实验：普通文件、目录、有效及悬空链接、FIFO、Unix 域套接字；用 --unknown 显式模拟未知分支。
- 机制：用户态 DIR 缓冲、目录 fd 与 struct file、getdents64 返回类型、ext4 类型映射、fstatat 重新查找。
- 工程成果：entry_types.c 完整实现；接口选择表；返回值、errno、资源与并发边界。
- 不展开：递归目录算法、安全打开方案的完整实现、文件系统性能比较。
