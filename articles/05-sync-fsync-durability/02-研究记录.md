# 研究记录

环境：macOS 14.8.8，Apple clang 16.0.0。

编译：

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -O0 -g sync_demo.c -o sync_demo
```

运行：`./sync_demo`

实际输出：

```text
write(data) = 12
fsync(data) = 0
write(meta) = 12
fdatasync(meta) = 0
sync() requested
```

资料：[POSIX `fsync`](https://pubs.opengroup.org/onlinepubs/9699919799/functions/fsync.html)、[Linux `fsync(2)`](https://man7.org/linux/man-pages/man2/fsync.2.html)、[Linux `sync(2)`](https://man7.org/linux/man-pages/man2/sync.2.html)、[Linux `open(2)`](https://man7.org/linux/man-pages/man2/open.2.html)。
