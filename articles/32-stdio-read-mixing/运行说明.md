# 运行说明

依赖 POSIX 普通可定位文件。程序用 tmpfile，结束时 fclose 清理。

```sh
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow read_one.c mixing_probe.c -o /tmp/mixing-probe
/tmp/mixing-probe
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow read_one.c read_one_test.c -o /tmp/mixing-test
/tmp/mixing-test
cc -std=c17 -Wall -Wextra -Wpedantic -Wconversion -Wshadow -Dread=test_read read_one.c error_test.c -o /tmp/mixing-error-test
/tmp/mixing-error-test
```

verify.py 会重复上述编译运行并生成 verification.json 与 actual-output.txt，
随后检查正文片段和 HTML 是否一致。需已有 wechat.html，并安装 bs4、Pillow。
